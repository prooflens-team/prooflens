# PROOFLENS 광고 분석 AI 모듈

## 1. 모듈 개요

Gemini API를 활용하여 광고 문구 및 이미지에서 제품 정보, 효능 주장, 사용 조건을 추출하는 모듈입니다.

추출된 효능 주장은 RAG 기반 근거 검색 및 검증 모듈의 입력 데이터로 활용됩니다.

## 2. 주요 기능

- 광고 텍스트 분석
- 광고 이미지 분석(최대 5장)
- 텍스트 및 이미지 복합 분석
- 제품명 및 카테고리 추출
- 효능 주장 및 사용 조건 추출
- 중복 주장 제거
- 서로 다른 제품의 광고 입력 제한
- Pydantic 기반 JSON 구조 검증
- API 및 입력 오류 처리

## 3. 개발 환경

- Python 3.11.3
- Gemini 3.1 Flash-Lite
- Google Gen AI SDK
- Pydantic
- python-dotenv
- pytest

## 4. 환경 설정

backend 디렉터리에서 가상환경을 생성하고 requirements.txt에 명시된 라이브러리를 설치합니다.

.env.example을 참고하여 .env 파일을 생성하고 GEMINI_API_KEY와 GEMINI_MODEL을 설정합니다.

## 5. Express 연동

Express 서버에서 Python의 ai/run_analysis.py를 실행하고 표준 입력(stdin)을 통해 UTF-8 JSON 데이터를 전달합니다.

**입력 필드**

| 필드       | 자료형   | 설명                  |
| ---------- | -------- | --------------------- |
| copy       | string   | 광고 문구             |
| imagePaths | string[] | 광고 이미지 파일 경로 |

광고 문구와 이미지 중 하나 이상이 필요하며, 이미지는 최대 5장까지 입력할 수 있습니다.

이미지 경로는 절대 경로 또는 backend 디렉터리 기준 상대 경로를 사용합니다.

**출력 필드**

| 필드    | 자료형  | 설명           |
| ------- | ------- | -------------- |
| success | boolean | 분석 성공 여부 |
| result  | object  | 광고 분석 결과 |
| error   | string  | 분석 실패 사유 |

정상 실행 시 종료 코드 0, 오류 처리 시 종료 코드 1을 반환합니다.

## 6. RAG 모듈 연동

정상 응답의 result 객체를 RAG 모듈에 전달합니다.

- result.ad: 광고 및 제품 정보
- result.claims: 검증 대상 효능 주장
- result.claims[].id: 주장 식별자
- result.claims[].text: 효능 주장 내용

광고 분석 모듈은 효능 주장의 사실 여부를 판단하지 않습니다. 근거 검색, 출처 수집 및 신뢰도 판정은 RAG 모듈에서 수행합니다.

## 7. 테스트 결과

pytest를 활용한 자동화 테스트 10개를 모두 통과하였습니다.

텍스트 분석, 이미지 분석, 복합 분석 및 JSON 입출력 인터페이스에 대한 수동 테스트도 수행하였습니다.
